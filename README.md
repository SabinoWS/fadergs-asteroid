# fadergs-asteroid

Asteroids no navegador para quem quer jogar a versão clássica de vetores, sem instalar nada.

A nave gira com as setas ou com WASD, acelera para a frente e freia. Asteroides entram pelos quatro lados. O tiro sai da ponta da nave.

## Stack

- TypeScript
- Vite
- Canvas 2D
- npm

## Local

```bash
npm install
npm run dev
```

O Vite mostra o endereço local, em geral `http://localhost:5173`.

## Build

```bash
npm run build
```

A pasta `dist/` é o que a Netlify publica. O `netlify.toml` define o comando de build e esse diretório.
