# Spec drive

Cada funcionalidade é uma pasta numerada dentro de `working/`. Todo markdown fica dentro da pasta da funcionalidade. O `README.md` da pasta é o checklist e tem três blocos:

1. **Requisitos** — o que precisa ser verdade para a funcionalidade existir.
2. **Desenvolvimento** — o que implementar para atender os requisitos.
3. **Testes** — como verificar que os requisitos foram atendidos.

A funcionalidade só fecha quando os três blocos estão marcados. A próxima funcionalidade só começa depois que a anterior estiver fechada.
